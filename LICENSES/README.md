`MIT-legacy.txt` 是迁到 GPL-3.0-only 之前，本仓库根目录 `LICENSE` 的逐字节副本。其中的版权声明（`Copyright (c) 2026 Near`）和 MIT 许可声明都没有改动。

在这次迁移之前，已经按该 MIT 许可证取得第一方材料的人，原有许可仍然有效。这份文件用来保留那些已经发出的许可，不是迁移之后版本的现行许可证，也不能拿来替代根目录的 GNU GPLv3。

迁移之后，本仓库第一方材料的许可见根目录 `LICENSE`（未经修改的 GPLv3 正文）和 `README.md` 的「许可证」一节，SPDX 标识符为 `GPL-3.0-only`（仅第 3 版）。

本目录不收录、不改写第三方依赖、数据、模型或素材的许可证与署名。
